# Handy

Handy — среда для нетребовательных локальных нейросетей. В комплекте идёт RAG, встроенная память и гибкий механизм максимальной оптимизации контекста для достижения наилучшего качества ответов модели.

Нужные знания и сохранённые факты подгружаются по запросу. Длинные ответы инструментов сокращаются, а полные результаты остаются доступны отдельно. Схемы, подсказки и проверка параметров помогают локальным моделям правильно вызывать инструменты.

Терминальная часть работает на [pi](https://pi.dev). В приложении для macOS можно настраивать локальные модели, их параметры и MCP. Поддерживаются и внешние API.

## Установка и запуск

Нужны Python 3.11+, Node.js 22.19+ и npm. На Linux также нужен модуль Python `venv` (в некоторых дистрибутивах он устанавливается отдельно). Для локальных GGUF-моделей нужен `llama-server`.

Скачай архив исходников из Releases и распакуй его в постоянную папку, например `~/Applications/Handy`. Не удаляй и не перемещай её после установки: Handy использует файлы из этой папки.

На macOS установи Xcode Command Line Tools и открой `Install Handy.command`. На Linux установи из терминала:

```sh
cd ~/Applications/Handy
python3 scripts/install_cli.py
export PATH="$HOME/.local/bin:$PATH"
handy
```

На macOS эти команды тоже работают. Установщик создаёт окружение Python и устанавливает зависимости внутри папки Handy; команда добавляется в `~/.local/bin`. Чтобы команда находилась в новых терминалах, добавь эту папку в `PATH` в настройках оболочки.

В чате выбери модель через `/models`; управлять моделями и провайдерами также можно через `handy models` и `handy providers`. Графическое окно `handy --settings` доступно на macOS. Веса моделей скачиваются отдельно.
