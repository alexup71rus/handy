# Handy

Handy — среда для локальных нейросетей с RAG, встроенной памятью и экономией контекста.

Нужные знания и сохранённые факты подгружаются по запросу. Длинные ответы инструментов сокращаются, а полные результаты остаются доступны отдельно. Схемы, подсказки и проверка параметров помогают локальным моделям правильно вызывать инструменты.

Терминальная часть работает на [pi](https://pi.dev). В приложении для macOS можно настраивать локальные модели, их параметры и MCP. Поддерживаются и внешние API.

## Установка и запуск

Нужны Python 3.11+, Node.js 22.19+ и npm. Для приложения macOS также нужны Xcode Command Line Tools, а для локальных GGUF-моделей — `llama-server`.

Скачай архив исходников из Releases и распакуй его в постоянную папку, например `~/Applications/Handy`. Дважды открой `Install Handy.command` или запусти установку в терминале:

```sh
python3 scripts/install_cli.py
handy
```

Не удаляй и не перемещай эту папку после установки: команда и приложение используют файлы из неё. Установщик создаёт окружение Python и устанавливает зависимости в этой папке; системные Python и npm он не изменяет.

Установщик добавит команду в `~/.local/bin`; если она не находится, добавь эту папку в `PATH`. При первом запуске выбери модель через `/models` или открой настройки командой `handy --settings`. Веса моделей скачиваются отдельно.
